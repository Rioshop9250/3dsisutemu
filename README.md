# License Guard（Unity 2022 用）

FBX・プレハブなどの 3D モデルを **利用規約に同意しないと使えない** 形で配布するための Unity エディタ拡張です。

- 規約付きの暗号化パッケージ（`.lgpkg`）を作成
- 利用者は規約を読み「同意」しないとインポートできない
- パスワード／キーファイル／ツール埋め込みシークレットを組み合わせた **複合キー**
- 規約を書き換えたファイルは復号できない（規約が鍵の一部になっている）
- 規約は **自由記述** と **○×の簡易表示（VN3 ライセンス風）** のどちらか、または両方で作成可能
- インポート後も、未同意のプロジェクトではシーン配置・プレハブを開く操作・ビルドをブロック

## 導入

`Assets/LicenseGuard` フォルダを Unity プロジェクトの `Assets` 以下にコピーします。
**配布者と利用者の両方** にこのツールが必要です（利用者向けにはツールを同梱するか、別途配布してください）。

メニュー `Tools > License Guard` から使います。

| メニュー | 使う人 | 内容 |
|---|---|---|
| パッケージ作成（配布者向け） | 配布者 | FBX・プレハブを規約付き `.lgpkg` に書き出す |
| 保護パッケージを開く（利用者向け） | 利用者 | 規約を表示し、同意したらインポートする |
| ライセンス管理 | 利用者 | 導入済みパッケージの規約確認・同意・同意の撤回 |

## 配布者の手順

1. `Tools > License Guard > パッケージ作成` を開く
2. **保護するアセット**: FBX・プレハブ・フォルダをドラッグ＆ドロップ。
   「依存アセットも含める」でマテリアルやテクスチャも自動で含まれます（「書き出されるファイル」で確認可能）
3. **パッケージ情報**: 名前・作者・バージョン・連絡先
4. **利用規約**
   - 表示形式: 「簡易表示＋自由記述」「簡易表示のみ」「自由記述のみ」
   - 簡易表示: 項目ごとに `○ 可 / × 不可 / △ 要相談 / ― 指定なし` と補足を設定。項目の追加・削除・並べ替えも自由
   - 自由記述: 好きな文章を書けます
   - 「テンプレート保存／読込」で規約を JSON として使い回せます
   - 「テキストでコピー」で BOOTH 等の商品説明に貼れる文章になります
5. **保護設定（複合キー）**
   - パスワード（任意）
   - キーファイル（任意）: 「新規作成」で乱数のキーファイル（`.lgkey`）を作れます。`.lgpkg` とは **別の経路** で渡してください
   - 鍵導出の強度: 大きいほど総当たりに強く、開くときに時間がかかります
6. 「暗号化パッケージを書き出す」

> パスワードとキーファイルは作成者側にも保存されません。忘れると作成者自身も復号できないので、元データは別に保管してください。

## 利用者の手順

1. `Tools > License Guard > 保護パッケージを開く` で `.lgpkg` を選ぶ
   （`.lgpkg` をプロジェクトに入れてダブルクリックしても開けます）
2. 規約・含まれるファイルを確認
3. 「上記の利用規約をすべて読み、同意します」にチェック
4. 必要ならパスワード／キーファイルを指定して「同意してインポート」

インポートすると、次の2つが作られます。

- `Assets/LicenseGuardLicenses/*.lglicense` … どのアセットがどの規約で保護されているか
- `ProjectSettings/LicenseGuardAgreements.json` … このプロジェクトでの同意記録

## 未同意のときにブロックされる操作

保護アセットが **同意記録のないプロジェクト**（例: フォルダごと別プロジェクトにコピーした、同意を撤回した）にある場合:

- シーン／プレハブ編集画面に置くと自動で取り除かれ、規約画面が開く
- プロジェクトウィンドウでダブルクリックしても開かない（規約画面が開く）
- ビルドに含まれているとビルドが失敗する
- プロジェクトウィンドウに鍵アイコンが表示される

`Tools > License Guard > ライセンス管理` で規約を読んで同意すると使えるようになります。

## 暗号の仕組み

```
鍵素材 = 連結( SHA-256(ヘッダ＝規約・ファイル一覧・salt 等),
               パスワード,
               SHA-256(キーファイル),
               ツール埋め込みシークレット )
鍵     = PBKDF2-HMAC-SHA256(鍵素材, ランダム salt, 反復回数)  → 暗号鍵 + MAC 鍵
本体   = AES-256-CBC で暗号化した .unitypackage
改ざん検知 = HMAC-SHA256（ファイル全体。検証に通るまで1バイトも復号しない）
```

- 要素のどれか1つでも違えば鍵が変わり、復号できません
- 規約は同意前に表示するため平文ですが、鍵の一部なので **書き換えると開けなくなります**
- 復号した `.unitypackage` は一時フォルダに置かれ、インポート後すぐ削除されます

ファイル形式: `"LGPK" | ヘッダ長 | ヘッダ(JSON) | IV | 暗号文 | HMAC`

## 「Unity 以外で解読されないように」について（できること・できないこと）

正直に書いておきます。**クライアント側だけで完結する仕組みである以上、完全な防止はできません。**
本ツールは「手軽に抜かれない・規約を読まずに使われない」ための抑止策です。

**できていること**

- `.lgpkg` は独自形式の暗号ファイルなので、Blender 等の他ソフトや一般的な解凍ツールでは開けません
- ツール埋め込みシークレットを鍵に混ぜているため、パスワードとキーファイルが漏れても
  このツール（Unity 上の License Guard）を通さないと鍵を作れません
- 未同意のプロジェクトでは、シーン配置・プレハブを開く・ビルドを止めます

**できないこと（原理的な限界）**

- **インポート後の FBX は Unity の仕様上、プロジェクト内に通常の FBX ファイルとして置かれます。**
  Unity で使える状態にした時点で、そのファイルをコピーすれば他ソフトでも開けます
- 埋め込みシークレットはツールのコード内にあるので、C# を逆コンパイルすれば取り出せます
- `.lglicense` や本ツールを削除すれば、プロジェクト内でのブロックは外れます

**より強くしたい場合**

1. `Assets/LicenseGuard/Editor/Core/BindingSecret.cs` の値を自分だけの乱数に書き換える
   （変えると他の License Guard で作った `.lgpkg` とは互換性がなくなります）
2. `Editor` フォルダを DLL にビルドし、難読化ツールをかけて配布する
3. パスワードを購入者ごとに変える／キーファイルを購入者ごとに渡す
4. 規約には「Unity 以外のソフトウェアへの持ち出し: × 不可」を入れておく（初期項目に入っています）。
   技術的に防げない部分は、規約と法的手段で守ることになります

## 動作確認

- 暗号コア（`LgCrypto` / `LgpkgFile`）は .NET 8 上でテスト済み:
  PBKDF2 の公式テストベクタ（RFC 7914）、各サイズでの往復、誤パスワード・誤キーファイル・
  規約の改ざん・本体の改ざん・途中切れファイルの拒否
- エディタ拡張全体は Unity 2021.1 の参照 DLL でコンパイル確認済み
  （`PrefabStage` の名前空間のみ 2022 用。**Unity 2022 実機での動作確認はまだ** です）

## フォルダ構成

```
Assets/LicenseGuard/Editor/
  LicenseGuard.Editor.asmdef   エディタ専用アセンブリ（ビルドには含まれません）
  Core/
    LgCrypto.cs         暗号処理（PBKDF2・AES・HMAC）
    LgpkgFile.cs        .lgpkg の読み書き
    BindingSecret.cs    ツール埋め込みシークレット
    LicenseTerms.cs     規約データ（○×項目・自由記述・クレジット）
    Models.cs           ヘッダ・マニフェスト・同意記録
    LicenseRegistry.cs  同意記録と保護アセットの管理
  Guard/
    ProtectedAssetGuard.cs  未同意アセットのブロック・ビルドチェック
  UI/
    PackWindow.cs           パッケージ作成画面
    ImportWindow.cs         同意・インポート画面
    LicenseManagerWindow.cs ライセンス管理画面
    TermsGUI.cs             規約の表示・編集 GUI
```

※ 簡易表示は VN3 ライセンスの「○×で一覧できる」形式を参考にした独自の表示です。VN3 ライセンスそのものではありません。
VN3 ライセンスを使いたい場合は、公式の規約文や URL を自由記述・規約全文URL に入れてください。
